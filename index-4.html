⚙️ Google Drive Setup

Google Drive backup ke liye ek baar Google Cloud OAuth Client ID chahiye (free).

  1. Google Cloud Console kholo
  2. Project banao → APIs: enable Google Drive API
  3. Credentials → Create OAuth client ID → Web application
  4. Authorized JavaScript origins mein apni file ka origin add karo
    (local file ke liye: http://localhost ya Live Server URL)
  5. Client ID copy karke yahan paste karo

Client ID sirf aapke browser mein save hota hai.
